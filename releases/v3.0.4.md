### 更新内容

- 动效已与老版本完全一致
- 敲数字梗冒 5 枚 emoji
- 敲 notesync 放 20 颗金点
- 时长缓动位置逐条对齐

上一版把数字梗与 `notesync` 烟花的动效"修出来了"，但**做出来的不是老版本那个动效** ——
这一版才是对齐。

根因是**载体不对**：老项目这两个动效都是 **DOM `<i>` + CSS keyframes**
（`index.html:6688-6705` 的 `div.ns-burst`、`:6757-6778` 的 `div.ns-fw`），
重写版却在 canvas 里用 rAF 重画了一遍。载体不同，四条曲线就全不一样：
位移范围（老项目是横向 ±35px、朝上 30–70px，重写版是环形放射 + 重力）、
时长（.95s / 1.2s）、缓动（`ease-out` / `cubic-bezier(.12,.68,.35,1)`）、
缩放与透明度（`scale(.6→1.15)`、`opacity 0→1@15%→0`）。
看着"有动效但就是不对"，正是这个。

现在逐字回到老项目：

1. **数字梗**：`div.ns-burst` 钉在光标处，里面 5 个 `<i>` 各带一组
   `--nx` / `--ny` / `--nr`，靠 `@keyframes nsBurstUp .95s ease-out` 飞出去，
   `animationDelay` 是 `i*0.03`（依次冒出，不是随机）；字号 16px，1300ms 后自毁。
2. **notesync 烟花**：`div.ns-fw` 里 20 个圆点（`border-radius:50%` + `background:var(--accent)`），
   沿 `2πi/20` 均分方向飞向固定终点，走 `@keyframes nsFwOut 1.2s cubic-bezier(.12,.68,.35,1)`
   —— 强 ease-out，不是匀速直线；尺寸 3–8px、随机延迟 0–0.12s，1500ms 后自毁。
3. 两处都 `z-index:58`（老项目同值）：高于编辑器与粒子画布，低于提醒卡与菜单遮罩。

canvas 粒子层现在**只留给节日雨**，数字梗与烟花的"金点""延迟"分支已删（那两类粒子
不再有 canvas 生产者，留着是死代码）。

判据：新增 `test/egg-fxplan.test.mjs`（FXPLAN-01~08，把粒子参数抽成纯函数钉数值：
5 枚 / 20 颗、位移与半径区间、`i*0.03` 递增、注入随机源反推公式），
e2e `EGG-E14` / `EGG-E15` 改为读**真实 DOM 与 computed style**（动画名 `nsBurstUp` /
`nsFwOut`、时长、缓动、`z-index`、圆点半径），并反向断言"不该出现 canvas 粒子层 `#nsFx`"。
已做变异验证：位移改成朝下、delay 抄成随机式、CSS 时长改 1.4s，三处均能转红。
