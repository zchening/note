### 更新内容

- 数字梗粒子回来了
- 敲 notesync 放金色烟花
- 每次成梗都会再放
- 四个梗各有各的表情

正文里敲出 `1314` / `666` / `520` / `233` 会从光标处冒一串 emoji（🎆 / 🔥 / 💕 / 😂），
敲出 `notesync` 会在光标处放一朵金色点阵烟花 —— 这两样是老项目 `index.html:5363`
与 `:5463` 的既有行为，重写版此前一直没有。

本次实际修掉的是**两个叠在一起的根因**：

1. **扫描入口挂错了对象**：`buildEggLayer` 把扫描函数挂到外部传进来的 hooks 上，
   而调用方拿着的是返回对象 —— 两边不是同一个对象，于是条件触发**一次都没跑过**
   （且零报错）。现在它是返回对象上的正式方法 `scanEggs`。
2. **动效被"是否首次发现"门控**：老项目里"放动效"与"记图鉴"是两件事，
   动效由跳变闩锁驱动、每次成梗都放；重写版把两者合成一句
   `if (markDiscovered(...)) burst(...)`，而 `markDiscovered` 只在首次返回 true
   并写进 localStorage ⇒ 第一次之后再也不放。现在两者重新拆开：
   动效归闩锁，图鉴只记账。

顺带修掉几处让"动效看着像没生效"的实现问题：`burst` 按 UTF-16 **码元**取 emoji，
把 🔥💕🎆😂 拆成半截代理项（画出来是方框）；`ctx.font` 写了 `var(--mono, …)`，
而 canvas 2d 上下文**不解析** `var()`，赋值被静默丢弃 ⇒ 粒子一直按默认 10px 画、
`p.size` 完全失效。判定面也从"整篇包含该数字"改回老项目的**光标前缀尾匹配**，
并给程序化重建（初始装载 / 远端回灌 / 提醒到点）打了 tag，避免"打开一篇本来就有
1314 的笔记"一进去就炸一次。

判据：新增 `egg-gag.test.mjs`（GAG-01~07，纯逻辑）与 e2e `EGG-E14` / `EGG-E15`
（包裹 canvas 的 `fillText` 与 `arc`，记录真实画出去的东西）。
