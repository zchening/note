首屏出现过一种与界面风格完全不符的形态：「载入中…」、离线草稿冲突条、两个系统默认小按钮同时以浏览器默认样式露出。机制是 HTML 到了但 app.css 与 app.js 都没生效：`#draftBar` 起步靠 `.hidden` 藏住，而这条规则只定义在外链 app.css 里；`#boot` 本该由 app.js 末尾移除。

修法：构建模板在 stylesheet 之前内联三条纯结构规则（`.hidden`、`html,body` 高度链、`#boot` 居中），零颜色、零 JS、零版本号，class 显隐契约一字不动。外链 CSS 正常加载时由后加载的 app.css 覆盖，日常行为零变化。

判据 e2e 34：拦资源返回 404 + JSON + nosniff 复刻「资源不可得」形状，断言 computedStyle、可见性与几何；剥掉内联块的变异必须重现裸奔；真源与产物都钉顺序。先红后改，单测 1304、e2e 317、typecheck、首屏闸全绿。
