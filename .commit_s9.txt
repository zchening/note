## P0（测试长期全绿，用户实际用不了）

1. **扫一扫浮层从未挂载**（第 12 条）
   scan/layer.ts 建好 overlay 后只 append 到 box，从未 document.body.appendChild。
   症状：点扫一扫 → 浏览器弹摄像头权限 → 允许 → 屏幕什么都不出，控制台零报错。
   之所以长期全绿：cleanup() 里已写好 removeChild（读起来像挂载也完成了），
   而 e2e 10-scan 只查 querySelector('#scanMask') !== null —— 那只证明对象建出来了。
   守护：SCAN-E07 判据由 `count <= 1`（0 也满足！）改为 MutationObserver 观测
   「挂载发生过 >=1 且 <=1」+ 相机不可用时必须给可见原因。

2. **记忆解锁后二维码配对永远提示"解锁后才可使用"**（第 13 条）
   route() 的 unlockIfRemembered 成功分支没设 sessionPass → 配对码拿不到载荷。
   刻意不照抄老项目：老项目 raw key 明文存 localStorage，所以"记忆解锁后出码"天然成立；
   本项目 CryptoKey 是 extractable:false，为出码降级成可导出，等于把
   「XSS 拿到密钥即可离线解开全部历史密文」请回来。改为给「锁定笔记」的可执行出路。

3. **折叠对真实用户不可达**（第 19 条）
   behaviors.ts 的 rest.trim() !== '' 要求 [折叠] 之后必须为空，
   而老项目 index.html:4101 foldLeadInfo 只看行首。删限制 + 补 startsClose 短路
   （闭合锚 [/折叠] 绝不能建新组，老项目走 foldEndKind 另一套）。

4. **AutoLinkNode type 对不上**（第 20 条）：registerAutoLink 注册 'autolink'，
   而序列化只认 'link' → auto-link 出来的链接往返即丢 href。

5. **body 缺 display:flex; flex-direction:column**（第 3 条）
   老项目 index.html:96 有，拆 font 简写时整条丢了 → 纵向布局链全断 →
   编辑器不撑满、底部菜单栏随内容滚动。.shell 同步补 flex:1。

6. **时间 chip 常驻空圆角矩形**（第 2 条）：buildChip 初始 class 缺 hidden。
